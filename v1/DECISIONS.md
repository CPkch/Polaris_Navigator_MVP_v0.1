## 미정이던 동작의 결정
- 아코디언(M2): 한 번에 하나만 펼침, 펼친 행을 다시 누르면 접힘. 처음엔 첫 행 펼침.
- 칩(M3): 커서 위치에 "칩 글자 + 공백" 삽입. 같은 칩을 또 누르면 또 들어감(제한 없음). 글자 수 제한 없음. 칩의 선택 표시는 입력 문장에 그 글자가 포함되어 있는지로 판단 — 글자를 지우면 표시도 풀림.
- 다 썼어요 버튼: 입력을 다 지우면(공백만 남으면) 다시 비활성.
- 처음으로(M4): 쓴 문장 유지 (스펙 §5 "M1(문장 유지)").
- 문장 저장: localStorage['polaris.sentence'], 입력 즉시 저장. 비교 채점 없음.
- 갈래에서 연 X1: 확인하는 문장 = 그 갈래 설명, 출처 = F1(매출 비중 자료). F1은 문단이 아니라 수치라 형광 없이 내용 그대로 표시, "형광 = …" 캡션도 숨김.
- P1 원문이 비어 있는 동안: 원문 카드에 "원문 확인 중"만 표시 (스펙 §5).
- X1 형광: 피그마 v4 렌더대로 진초록(#1F9D55) 배경 + 검정 글자. (스펙 v1.1의 "22% 배경"은 구 팔레트 기준이라 안 씀.)
- 선택된 칩: 초록 12% 배경 + 초록 테두리 + 초록 글자 (피그마 M3b 렌더 기준).
- 상태 바(9:41): 피그마 목업용이라 구현 안 함 (명세서 §3 공통).
- 스크롤 복원: X1을 열 때 scrollY를 기억, 뒤로 가면 그 위치로 복원. 화면 전환(M1→M2 등)은 맨 위로.
