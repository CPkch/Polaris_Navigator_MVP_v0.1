# 다음 세션 작업 지시 (Opus용)

Fable이 2026-10-16에 A안(목록형) 전체 소스를 작성해 둠. 설계 판단은 끝났고, 아래는 확인·반복 작업만 하면 된다. 구조나 토큰 값을 바꾸지 말 것. 판단이 필요한 새 문제가 나오면 바꾸지 말고 사용자에게 보고.

## 할 일 (순서대로)
1. `npm install`
2. `npm run build` — 금지어 검사(prebuild) + tsc + vite 빌드. 오류가 나면 **오류 메시지가 가리키는 그 지점만** 고치고 다시 빌드. 설계 변경 금지.
3. `npm run dev` 로 띄워서 완료 조건 6개 확인 (docs/POLARIS_MVP_SPEC.md §7):
   1. M1 → M2 → M3 → M4 → M1이 버튼만으로 돈다
   2. M1·M2에서 X1 열고 뒤로 가면 원래 자리(스크롤 포함)
   3. M3 빈 입력이면 버튼 비활성, 새로고침해도 문장 유지
   4. 390px에서 가로 스크롤 없음
   5. 금지어 검사 통과, 고지 문구 모든 화면 하단
   6. 이미지 자리는 회색 상자(아직 이미지 없음)
4. 확인되면 커밋. 메시지 예: "Build MVP plan A (list) — 5 screens, static data"

## 참고
- 기준 문서: docs/POLARIS_MVP_SPEC.md (맨 위 주의 문구 먼저), docs/DECISIONS.md
- 데이터는 src/data/samsung.json 하나. 문장·숫자를 코드에 하드코딩하지 말 것.
- 이미지와 P1 원문은 사용자가 나중에 넣음 — 기다리지 말 것.
