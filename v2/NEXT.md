## 할 일 (순서대로)
1. `cd v2 && npm run build` — 오류가 나면 **오류 메시지가 가리키는 그 지점만** 고치고 다시 빌드.
2. 헤드리스 크롬 검증. 지난번 스크립트 `verify-v2.mjs`(세션 eea62101 스크래치패드 `driver/`)를 복사해 `verify-v2s.mjs`로 만들고, **앞부분에 S 흐름 검사를 추가**한 뒤 기존 M 검사는 그대로 이어서 돌릴 것. 기존 검사 중 바뀌어야 하는 것: "M1 뒤로 버튼 없음" → "M1 뒤로 버튼 있음, 누르면 S5"; 마지막 "처음으로 → M1" → "처음으로 → S1". 시작 화면이 S1이므로 M1까지 가는 경로(S1 예시 둘러보기 → S5 → 기업 분석)를 M 검사 앞에 넣을 것.
   S 흐름 검사:
   1. 새로고침 후 S1(브랜드 알약 + "보유 종목 사진을" 제목). 헤더 뒤로 버튼 없음
   2. "사진 선택" → 시트 열림(`.bottom-sheet`), "취소" → 닫힘, 바깥(`.dim`) 탭 → 닫힘
   3. 시트에서 "앨범에서 선택" → S3("사진 읽는 중"), 파일 입력 요소 없음(`input[type=file]` 0개)
   4. S3 진행 막대 폭이 0에서 커지고, 약 1.5초 뒤 자동으로 S4("인식 완료", Callout = 삼성전자)
   5. S3에서 1.5초 전에 뒤로 → S1로 가고 **S4로 튀지 않음** (타이머 정리 확인)
   6. S4 "다시 올리기" → S1. S4 "디오라마 보기" → S5
   7. S5 디오라마 이미지가 실제로 로드됨(`naturalWidth > 0`), 종목 줄 = 삼성전자 / 반도체. 종목 줄 탭 → M1, 뒤로 → S5, "기업 분석" → M1
   8. S1 "사진 없이 예시 둘러보기" → S5 바로(S3·S4 안 거침)
   9. M4 "처음으로" → S1, 쓴 문장은 localStorage에 남음
   10. 모든 S 화면: 고지 문구 1개(S3는 피그마에 없으니 0개도 허용 — 스펙 §4 "화면마다"와 어긋나는데 S3는 1.5초 지나가는 화면이라 Fable이 뺐음. 사용자에게 한 줄 보고), 가로 스크롤 없음, 시트 바닥까지
3. 스크린샷 390 너비: S1, S1+시트, S3, S4, S5. 사용자에게 보여줄 것.
4. 금지어 검사는 빌드에 포함되어 있으니 따로 안 해도 됨. 단, 새 UI 문구("사진 촬영", "앨범에서 선택", "기업 분석" 등)는 JSON이 아니라 코드에 있어 검사 대상이 아님 — 눈으로 금지어(매수·매도·추천·목표가·전망·사라·팔아라·유망·저평가·고평가) 없는지 한 번 확인.
5. 루트 README.md `v2/` 줄 끝에 " S1~S5 사진 흐름(시연용 흉내) 포함." 추가.
6. 확인되면 사용자에게 보고. **커밋은 사용자가 말할 때까지 하지 말 것.**
