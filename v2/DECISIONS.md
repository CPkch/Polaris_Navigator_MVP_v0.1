- 배경색이 프레임마다 다름(S1·S3 #F0EDE8, S4·S5 #F4F4F5, ① #F5F4F2). MVP 첫 화면 역할에 가장 가까운 ① 값으로 통일.
- 초록이 세 가지 섞여 있음(아이콘 #0A8F4C = 폐기된 옛 스펙 값, 진행 막대 #4A6741, 디오라마 아이콘 원 #4A7C6F). 페이지 이름이 "민트"라 **#4A7C6F 하나만** 씀 — 링크·진행 바·형광·선택 칩·링크 행 원.
- X1 형광: v1은 진초록 채움이었으나 민트는 채우면 글자가 안 읽혀 12% 배경으로.
- 헤더 오른쪽 "출처" 아이콘: Screens v1에 있지만 스펙 §1에서 뺀 항목이고 M2에서는 어느 출처인지 모호해 넣지 않음. 출처는 링크 줄로.
- 요약 카드 아래 출처 줄: 스펙 §4 "출처 줄 없음" 유지.
- Screens v1 고유 화면(사진 업로드 S1~S4, 디오라마 S5, AI 대화 ①, 데스크톱 ②): 만들지 않음. MVP 범위 밖.
- 아코디언 카드: 행과 펼침 패널을 `.seg` 하나로 감싸 테두리가 끊기지 않게 함. v1은 행/패널이 따로였음.

## S 화면 추가 (2026-10-16 저녁, 사용자 요청)
Screens v1의 사용자 흐름을 M 화면 앞에 붙임. **시연용이라 사진은 흉내만 낸다** — 파일 창 없음, 인식은 항상 `company.name`.

흐름: S1 시작 → (S2 사진 올리기 시트) → S3 읽는 중 → S4 인식 완료 → S5 디오라마 → M1 → M2 → M3 → M4 → 처음으로 = S1. S1 "사진 없이 예시 둘러보기"는 S3·S4를 건너뛰고 S5로.

- S2는 별도 화면이 아니라 S1 안의 오버레이(`components/UploadSheet.tsx`, 상태는 S1 로컬). 두 줄 중 무엇을 눌러도 S3. 취소·바깥 탭이면 닫힘.
- S3는 진행 막대가 1.5초(`READ_MS`) 동안 선형으로 차고 자동으로 S4. 뒤로는 S1.
- S4 "다시 올리기"는 S1. 인식 결과 Callout은 피그마가 Regular 24였으나 토큰에 없는 크기라 Title(22/30) Regular로.
- S5 뒤로는 S1(예시 둘러보기로 왔을 땐 S4를 안 거쳤으므로 S4가 아니라 S1). 종목 줄과 "기업 분석" 버튼 모두 M1.
- S5 종목 줄의 부제 "반도체"는 피그마 문구. 코드 하드코딩 금지 규칙에 따라 `company.industry`를 v2의 samsung.json에 추가. (`docs/samsung.json`에는 안 넣음 — v2에서만 쓰는 표시용 라벨.)
- 디오라마 이미지: 피그마 S5 프레임에서 받은 파일. 확장자는 png였지만 실제 JPEG 1024×1024라 `images/diorama.jpg`로 저장, JSON 경로도 맞춤. 스펙 §8의 "PNG 2배 780×800"은 디오라마 콘셉트(B안)용이라 여기 적용 안 함.
- M1에 뒤로 버튼 생김(→ S5). 스펙 §4 "M1에서는 없음"은 M1이 첫 화면일 때 기준이라 바꿈. M4 "처음으로"는 S1.
- 새로고침하면 S1부터. 쓴 문장은 그대로 남음.
- S1 상태 바(9:41), 시트 그림자(피그마 `shadow 0 -4 20`), AI 대화 ①, 데스크톱 ②: 넣지 않음. 그림자는 스펙 §3 "그림자 없음".
- S1 배경: 피그마는 #F0EDE8이지만 앞서 정한 대로 캔버스 #F5F4F2로 통일.
- 새 아이콘 camera·upload는 기존 세트와 같은 규격(24 viewBox, stroke 2)으로 `icons.tsx`에 추가. 피그마 SVG는 옛 초록(#0A8F4C)이 박혀 있어 쓰지 않음.
